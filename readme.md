# Bot Telegram VendingPrint

Cara menjalankan:

1. Buat file `.env`
2. Isi `.env` dengan:
```
TELEGRAM_BOT_TOKEN=xxx...
```

3. Install dependencies:
```
pip install -r requirements.txt
```
4. Jalankan program:
```
python3 main.py
```

5. Test kirim pesan dan file di bot telegram yang dibuat (dalam kasus ini https://t.me/vendingprint_syuhada_taufiq_bot)
